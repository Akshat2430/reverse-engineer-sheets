# Proof reports

One per sample workbook, from `prove RUN --seed 47111` on the final rebuild of each scored run. The seed was drawn at random after all runs had finished, so none of the 300 random cases was seen while building. Each report also replays every probe run, which the rebuild was built with, so those cases are not unseen. Tolerance: 0.000001, or one part in a billion for large totals. Engine: Excel 16.114.2 on macOS, locale en_IN.

The sales commission run is published in full as the demo (`runs/demo/`), rebuild included, so that workbook's planted problems are public. The other two rebuilds aren't published: their comments describe the planted problems, and their answer keys stay private so those two samples can still be used for blind runs.
